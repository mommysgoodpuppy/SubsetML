# AGENTS.md

SubsetML is a strict subset of Standard ML, a checker and two-way SML ↔ Workman (WM) translator,
and a custom portable Basis shared with Workman. The compiler targets MLton and MLWorks (PS2).

- `docs/`: specifications and design. Start with `README.md`, then `docs/spec.md` (language),
  `docs/basis.md` (library) and `docs/translation.md`.
- Write SubsetML, not general SML, even though the files are `.sml`: only the subset in
  `docs/spec.md` (no exceptions, references, functors or signatures) and the Basis conventions in
  `docs/basis.md` (data-first tuple arguments, `Result` with typed errors, `Subset*` modules
  instead of the SML Basis). Code that MLton accepts can still be rejected by `bin/subsetml check`.
- `src/*.sml` is the source of truth. `src/*.wm` files are generated by `make wm` and overwritten;
  edit the `.sml` file, never the `.wm` one.
- Authored portable code must pass `bin/subsetml check-portable ENTRY.sml`: no SML Basis
  structures or convenience pervasives. The compatibility `check` command alone does not
  establish portability. See `docs/runtime-dependencies.md` for kernel requirements,
  runtime-operation motivations and compiler source portability.
- Basis modules (`src/subset_*.sml`) have no host primitives unless the boundary is justified in
  `docs/basis.md`. Declare every module's source dependencies and primitive calls in
  `docs/basis-dependencies.json`; tests audit it against the parsed source. Update `docs/runtime-dependencies.md` for every
  new runtime operation, including a source alternative and necessity or measured performance reason.
- Host adapters live in `lib/` (`lib/mlworks/`, `lib/sml-basis/`); MLWorks/PS2 staging scripts are
  in `scripts/`. See `docs/sml-targets.md`, `docs/mlworks-ps2.md` and `docs/mlworks-batch.md`.
- Build: `make` (writes `bin/subsetml` with MLton). Check: `make selfcheck`. Test: `make test`
  (runs every suite; scope with targets such as `make custom-basis-check`, `make integer-check`
  or `make native-check`).
- `bin/` and `build/` are generated and ignored by Git.

## Related projects

- `../wm-mini`: the Workman compiler. It loads this Basis as library modules generated into
  `subml-basis/`, refreshed from wm-mini with `deno run -A scripts/sync_subml_basis.ts ../SubsetML`;
  WM programs import them as `"basis/x.wm"`, which `sml-entry --basis DIR` also resolves. Its
  `tooling/pakman-subsetml/`
  (pakman ported to SubsetML) and `tooling/won/` (WON) build with this repository's
  `bin/subsetml`.

## Git

Manage git however you see fit. Primary is `master`.

- Commit as the configured git identity. No `Co-Authored-By` or other co-author trailers.
- Never push, open PRs or issues, or publish anything to external sites unless asked for that
  specific action.
- End every agent-made commit message with:

  ```
  Agent: <harness> <version>; model <exact model id>; thread <harness thread/session id>
  ```

  For example, `Agent: Claude Code 2.1.296; model claude-opus-5-5; thread 941be8c7-aca1-4664-b284-7cc0eed69e21`.
